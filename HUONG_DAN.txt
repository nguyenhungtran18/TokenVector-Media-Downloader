Thu muc nay chua cac file thuc thi can thiet:

1. tv-downloader-gui.exe (Dung luong sieu nhe ~16 KB)
   - Click dup chuot truc tiep de mo giao dien do hoa Windows Forms.
   - Thuan Native Windows Forms (Subsystem GUI), khong co cua so den CMD.
   - Tu dong phan giai luong va tai media truc tiep bang HTTP Native cua TokenVector.
   - 100% Doc lap, KHONG can bat ky file phu thuoc hay yt-dlp.exe nao.

   - Co nut STOP huy tai tuc thi va tu dong don dep sach file do dang.

2. tv-downloader-cli.exe (~16 KB)
   - Ung dung chay qua command-line / terminal:
